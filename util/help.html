Filtro de Pesquisa

Permite filtras a partir de campos da tabela ou campos calculados usando outras informações. Basicamente, é possível utilizar os seguintes operadores:

  • Igual
  • Diferente
  • Contém
  • Não contém
  • Pertence
  • Não pertence
  • Está vazio
  • Não está vazio
  • Maior
  • Menor
  • Começa
  • Termina
Também é possível escolher o operador lógico, inclusive defindo ordem de prioridade na composição do filtro a partir da definição dos parênteses.
  • E
  • ) E
  • E (
  • ) E (
  • OU
  • ) OU
  • OU (
  • ) OU (

Agrupamento

Permite mostrar determinadas informações de forma agrupada, e a partir da definição dos campos e da ordem dos campos, exibe a quantidade de registros.

Baselines

Baseline são as infomações a partir das informações atuais, considerando o filtro. Posteriormente, é possível mostrar estas informações salvas e compará-las com as informações atuais.
