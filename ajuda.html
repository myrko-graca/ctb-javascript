Conceitos Gerais

Ajuda para utilizar o Sistema de Contabilidade Simples em Javascript. Este sistema é feito totalmente com código que roda no browser, não existindo comunicação com nenhum servidor após o carregamento. O sistema utilizar arquivos para gravar os dados e posteriormente ler, sendo que os arquivos são salvos exclusivamente no cliente, ocasionando ser desnecessário fazer qualquer tipo de login. Observa-se ainda que o sistema está adaptado para utilização no celular.

Para iniciar a utilização do sistema, é interessante carregar os dados de teste (menu "arquivo/abrir teste"), que contém informações que são usadas para entendimento básico do sistema, mas pode servir também como base do seu próprio plano de contas.

Ativo, Passivo, Receita, Custo e Despesa

Estas abas são referentes ao plano de contas, que devem ser construídas de acordo com definições próprias. É possivel indicar se a conta é sitética (isto é, não pode haver lançamento diretamente para ela) e também criar subgrupos. É interessante observar que ao clicar no ícone no lado esquerdo de cada subgrupo de contas (⛶) expande todo o subgrupo, facilitando o preenchimento a partir do isolamento das informações.

Resumo

Exibe todas as contas com numeração completa. Incialmente mostra apenas as contas que tenham valor, mas é possível mostrar todo o plano de conta ao clicar no respectivo botão

Lançamentos

Parametriza, efetua e exibe os lançamentos contábeis. Contém as seguintes abas:

Configurações

A primeira configuração é o controle de quantidade. Ao definir as contas de controle de quantidade, é exigido no lançamento que seja definida a quantidade, e também é possível calcular o valor baseado nos lançamentos de compra anteriores utilizando o método FIFO (first in first out). Obs.: As contas definidas podem ser as superiores, e funcionará para todas as contas filhas, como por exemple definindo a conta "estoque".

Na segunda configuração, são definidas contas para depreciação e aquelas relacionadas para indicar o valor depreciado, indicando a periodicidade e taxa de depreciação. Ao efetuar lançamento, é possível calcular automaticamente o valor depreciado.

Na terceira configuração, são atribuídos os atributos para calcular o Simples Nacional (caso optante). A partir dessas informações, ao efetuar lançamento, o valor é calculado automaticamente.

Tipos

Aqui são definidos tipos de lançamentos para facilitar o registro na efetivação do lançamento. Para cada tipo, são indicadas as possíveis contas para débito e para crédito (é possível definir qualquer conta que as contas filhas são consideradas automaticamente). Dessa forma, fica mais fácil os lançamentos contábeis se estruturado de forma adequada para sua empresa.

Efetuar

Aqui é efetuado o lançamento contábil, podendo escolher qualquer conta "não sintética". Utilizando o tipo, é possível restringir as contas de débito e crédito que podem ser usadas, com a finalidade de facilitar o lançamento contábil.

Visualizar

Aqui é possível visualizar os lançamentos contábeis realizados, permitindo filtrar os resultados a partir da conta, se for de débito ou crédito, e ainda em uma determinada data

Apuração de Resultado

Na primeira aba, mostra a conta transitória de apuração de resultado e permite indicar a conta de lucro/prejuízo

Na segunda aba, permite realizar a apuração de resultado (mensal) e permite relatórios de outros tipos (trimestral, anual, etc.), sendo necessário nesse caso marcar a opção "Relatório" para trazer as informações ignorando as apurações intermediárias. Após buscar os lançamentos relativos ao período definido, é exibido o ARE do período, e assim permite efetuar a apuração do resultado ao clicar do referente botão, realizando os lançamentos que irão "zerar" as contas de resultados, utilizando a conta transitória.
